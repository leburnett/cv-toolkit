# Full CV

**This file is a store, not a CV.** Nothing in it gets sent anywhere, so it
can be as long and repetitive as you like. Its whole job is to hold more
material than any single CV would use, so that tailoring one becomes a matter
of choosing rather than writing.

**How to use it:** every bullet below is written in the same markdown that
`cv_template.md` expects, so building a tailored CV is copy, paste, delete
what doesn't apply.

```
python3 cv_new.py 2026-10_acme_data-analyst
# paste the bullets you want into applications/2026-10_acme_data-analyst/cv.md
python3 cv_build.py applications/2026-10_acme_data-analyst --max-pages 2 --pdf
```

**How to add to it:** just append. Put a new bullet under the relevant
heading and don't bother picking the best phrasing or trimming an old one.
Several versions of the same fact sitting side by side is the point — that's
what gives you something to choose between later. If something doesn't fit a
heading, drop it under *Unsorted* at the bottom and move it whenever.

Suggested conventions, all optional:

- `*italic*` for publication venues, tools, supervisors; `**bold**` for lead-ins.
- `[long]` / `[short]` to mark two lengths of the same fact.
- `[unused]` for something you've never actually put on a CV.
- Write dates exactly as they should appear on the CV.
